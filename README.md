
# FinControl AI — CONTECSI USP

## Sobre o projeto

Este repositório reúne os materiais acadêmicos relacionados à preparação do artigo científico sobre o FinControl AI para o 21º CONTECSI USP — Congresso Internacional de Gestão da Tecnologia e Sistemas de Informação.

O FinControl AI é um sistema de gestão financeira pessoal que utiliza inteligência artificial para interpretar informações enviadas pelo WhatsApp, permitindo o registro e a consulta de movimentações financeiras, com apoio de uma aplicação web.

## Objetivo da pesquisa

Descrever o desenvolvimento e avaliar o funcionamento do FinControl AI, considerando a interpretação de movimentações financeiras, a consistência dos registros e a integração entre o WhatsApp e a aplicação web.

## Modalidade

PSE — Full Paper (Artigo Completo).
